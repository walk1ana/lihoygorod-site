# Лихой Город: всё в одном

- `site.html`: сайт одним файлом (открывается и просто в браузере, но без сервера живые данные не работают)
- `node/`: сервер на Node.js с живыми данными: онлайн, рекорды, новости (см. node/README.md)
- `csharp/`: сервер на C#, пока только раздаёт сайт, без онлайна, рекордов и новостей

В каждом сервере есть `render.yaml` для деплоя на Render.
